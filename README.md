# TDitbam Streamer Suite

A unified toolset for streamers, combining **Chat-TTS** and **CoreOptimizer**.

## Features
- **Chat-TTS**: Convert live chat from YouTube, Twitch, and TikTok into Thai speech.
- **Streamer Optimizer**: Optimize CPU usage for games (P-Cores) and background apps (E-Cores).
- **Auto-Translation**: Real-time translation to Thai.
- **System Cleanup**: Quick junk file removal to keep your system fast.

## Installation
1. Install requirements:
   ```bash
   pip install -r requirements.txt
   pip install psutil customtkinter darkdetect Pillow
   ```
2. Run the suite:
   ```bash
   python main.py
   ```
