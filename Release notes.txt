==================================================
   TDitbam Streamer Suite - Release Notes v3.3.0
==================================================

[ระบบซิงค์และประสิทธิภาพ / Logic Synchronization]
- ซิงค์ตรรกะการทำงาน (Logic) จากตัวทดสอบเข้าสู่ระบบหลัก เพื่อความเสถียรสูงสุด
- ปรับปรุงการเริ่ม/หยุดระบบ (Start/Stop Sequence) ให้ทำงานได้รวดเร็วและแม่นยำขึ้น
- เพิ่มการล้าง Log อัตโนมัติเมื่อเริ่มเซสชันใหม่ เพื่อการติดตามสถานะที่ชัดเจน

[ระบบตั้งค่าแบบ Real-time / Live Config Update]
- เพิ่มระบบ "Live Update": ปรับเปลี่ยนเสียง (Voice), การแปลภาษา (Translation), และความหน่วง (Delay) ได้ทันทีโดยไม่ต้องหยุดโปรแกรม
- ใช้ระบบ Variable Tracers เพื่อตรวจจับการเปลี่ยนแปลงค่าในหน้า GUI และส่งไปยัง Engine แบบเรียลไทม์

[มาตรฐานข้อมูลใหม่ / Standardized Configuration]
- ปรับปรุงโครงสร้าง 'config.ini' ให้เป็นมาตรฐานเดียวกัน (ใช้ Section [settings] และคีย์แบบตัวพิมพ์เล็ก)
- ระบบล้างค่าเก่า (Legacy Keys) อัตโนมัติเพื่อลดความซ้ำซ้อนของข้อมูล
- รองรับการดึงข้อมูลจากค่าเดิม (Backward Compatibility) ทำให้ผู้ใช้เก่าไม่ต้องตั้งค่าใหม่ทั้งหมด

[การปรับปรุง UI/UX / Interface Enhancements]
- ปรับปรุงการกรอกข้อมูลในหน้า Connections (YouTube, Twitch, TikTok) ให้เสถียรขึ้น
- เพิ่ม Event Bindings สำหรับช่องกรอกตัวเลข (Delay) ให้บันทึกค่าได้ทันทีเมื่อพิมพ์เสร็จหรือกด Enter
- ปรับปรุงระบบ Log บน Dashboard ให้แสดงผลแบบ Thread-safe และจัดการพื้นที่แสดงผลได้ดีขึ้น

[การติดตั้งและแจกจ่าย / Deployment]
- อัปเดตไฟล์ .exe (v3.3.0) พร้อมการขอสิทธิ์ Administrator ที่แม่นยำขึ้น
- สคริปต์ตัวติดตั้ง Inno Setup (v3.3.0):
  * ปรับปรุงการรวมไฟล์และจัดการ Versioning ใหม่
  * สร้าง Shortcut และ Uninstaller ตามมาตรฐาน Windows
