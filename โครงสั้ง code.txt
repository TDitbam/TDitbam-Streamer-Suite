โครงสร้างล่าสุด (6 สิงหาคม 2026)

main.py
- สร้าง ChatTTSEngine และเริ่ม GUI

gui/app.py
- จัดการหน้าหลัก config ภาษา shortcut และ lifecycle ของ UI

gui/i18n.py
- คำแปลภาษาไทยและ English (US)

gui/chat_frame.py
- ตั้งค่าแพลตฟอร์ม Bot Live Chat
- เลือก Voice Provider: edge, gtts, gemini, openai
- แสดงเฉพาะ panel ของ provider ที่เลือก

gui/logic.py
- บันทึก config และส่งค่าจาก UI ไปยัง engine

core/tts_engine.py
- Session isolation, cancellation, message/audio queues และ audio player
- สร้างเสียงผ่าน Edge TTS, gTTS, Gemini API และ OpenAI API

core/collectors/
- รับแชทจาก YouTube, Twitch และ TikTok
- ใช้ queue แบบไม่ block เพื่อไม่ให้ worker ค้างตอน Stop

หมายเหตุ: Gemini API Voice และ OpenAI API Voice อยู่ในขั้นทดลอง

main.py จะดึง gui มาเสร็จ
