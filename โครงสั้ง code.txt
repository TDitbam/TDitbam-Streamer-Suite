โครงสร้างล่าสุด (7 สิงหาคม 2026)

main.py
- สร้าง ChatTTSEngine และเริ่ม GUI

gui/app.py
- จัดการหน้าหลัก config ภาษา shortcut และ lifecycle ของ UI

gui/i18n.py
- คำแปลภาษาไทยและ English (US)

gui/chat_frame.py
- ตั้งค่าแพลตฟอร์ม Bot Live Chat
- เลือก Voice Provider: edge, gtts, gemini, openai
- แสดงเฉพาะ panel ของ provider ที่เลือก

gui/dashboard.py
- แสดงสถานะระบบ, usage ของ P-Core/E-Core และจำนวนคอร์ที่ Optimizer ใช้เทียบกับคอร์ทั้งหมด
- แยก Console Log เป็นแท็บ All Logs, Bot Live Chat และ Optimizer

gui/optimizer_frame.py
- Quick Add เลือกโปรเซสที่กำลังทำงาน
- Manual Entry สำหรับพิมพ์ชื่อหรือเลือกไฟล์ .exe แบบเดิม

gui/logic.py
- บันทึก config และส่งค่าจาก UI ไปยัง engine

core/tts_engine.py
- Session isolation, cancellation, message/audio queues และ audio player
- สร้างเสียงผ่าน Edge TTS, gTTS, Gemini API และ OpenAI API

core/collectors/
- รับแชทจาก YouTube, Twitch และ TikTok
- ใช้ queue แบบไม่ block เพื่อไม่ให้ worker ค้างตอน Stop

core/single_instance.py
- กันเปิดโปรแกรมซ้ำและส่งสัญญาณเรียกหน้าต่างเดิมจาก System Tray

icon.ico
- ไอคอนหลักสำหรับ window, tray, notification และ executable

build_exe.spec
- สร้าง `dist/StreamerSuite/StreamerSuite.exe` แบบ one-folder
- เก็บ dependency และไฟล์ประกอบแยกใน `dist/StreamerSuite/parts/`

installer_script.iss
- สร้าง Installer v3.6.0 แบบ Disk Spanning
- แยก payload ทุก 50 MB เป็นไฟล์ BIN ตามหมายเลข Part

build_release.ps1
- Clean build, สร้าง App EXE, Installer Parts และ SHA-256 manifests อัตโนมัติ

requirements-build.txt
- dependency สำหรับ build รวม PyInstaller

CREDITS.md
- เครดิตเจ้าของโครงการ, AI assistants, runtime libraries, Voice/API services และเครื่องมือ build/distribution

หมายเหตุ: Gemini API Voice และ OpenAI API Voice อยู่ในขั้นทดลอง

main.py จะดึง gui มาเสร็จ


หน้าที่หลักของ gui คือดึงฟักก์ชั่นของ
engine tts และ engine core
